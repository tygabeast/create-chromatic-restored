## What this addon contains
* One small Java class that adds Create's existing legacy items to Create's creative tab (and so to JEI).
* Five crafting recipes (data files) for Chromatic Compound, Shadow Casing and Radiant Casing.

## What it does NOT contain
It bundles **no textures, models, sounds, language files or code from Create**. The items (Chromatic Compound, Shadow Steel,
Refined Radiance, Shadow Casing, Radiant Casing) and their art still ship inside Create 6.0.x itself; this addon only
looks them up by ID at runtime. Create's assets are "All Rights Reserved" (c) The Create Team, and Create's code is MIT.
If a future Create version removes these items, this addon will do nothing.
